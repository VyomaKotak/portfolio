# Vyoma Kotak — Portfolio

Single-file dark-theme portfolio. No build step, no dependencies.

## Files (upload ALL of these together)
- index.html   — the site
- vyoma.jpg    — hero profile photo (index.html references it)
- cv.pdf       — CV, wired to the Download CV buttons
- vercel.json  — clean-URL config
- README.md    — this file

## Deploy to Vercel
1. Create a GitHub repo (e.g. `portfolio`), Public.
2. Upload all five files above into it, Commit.
3. vercel.com → sign in with GitHub → Add New Project → import the repo.
4. Framework preset: Other. Leave build command and output directory empty.
5. Deploy. You get a URL like `vyoma.vercel.app`.
6. Rename under Project Settings > Domains if you want a cleaner address.

## Edit later
Everything is in index.html. Edit, commit to GitHub, Vercel redeploys automatically.
